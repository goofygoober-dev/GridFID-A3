# Gridfinity Advanced Forge

A Streamlit Cloud app that traces a tool photo from an A3 grid board and generates a custom Gridfinity STL pocket tray.

## Streamlit Community Cloud

1. Push this folder to GitHub.
2. Open [Streamlit Community Cloud](https://share.streamlit.io).
3. Choose the GitHub repo, branch, and `app.py`.
4. Deploy.

The app uses `runtime.txt` to request Python 3.11 and `opencv-python-headless` for cloud-friendly image processing.
